Библиотека ВТК

Структура

server
Node.js сервер с REST API и файловой базой данных

client
PWA интерфейс без сборки

Запуск

1. Установить зависимости в папке server
2. Запустить сервер командой npm start в папке server
3. Открыть http://localhost:10216 в браузере
